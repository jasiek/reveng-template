# scratchpad/

Ephemeral per-wave working files — batch lists, subagent result JSON, consolidated
TSVs, the swept-band record. Gitignored, and safe to delete between waves.

Nothing durable lives here. If a wave produced something worth keeping, it belongs
in `FINDINGS.md`, in the ledger, or in Ghidra itself — the whole method assumes
this directory can vanish without losing work.
